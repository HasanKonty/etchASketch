# etchASketch

A browser-based sketchpad where you draw by hovering over a grid.

**[Live demo](https://hasankonty.github.io/etchASketch/)**

## Features

- Default 16x16 grid
- Button to set a custom grid size (1-100)
- Random color on hover
- Colors build up in opacity with repeated passes

## Built with

- HTML
- CSS
- JavaScript (DOM manipulation, event delegation)

## Run locally

1. Clone the repo: `git clone git@github.com:HasanKonty/etchASketch.git`
2. Open `index.html` in your browser
